# 05 — User Flows

Flows are described functionally — steps, decisions, and states — with no reference to layout or visual treatment. The primary actor is the **parent**; the child is the secondary actor during sessions.

---

## Flow 1 — Discovery → free screener → email (current acquisition flow)

```
Parent sees social post (myth-bust / "is my child on track?" / emotional)
        │
        ▼
Parent comments a keyword (e.g., a trigger word) or taps a link
        │
        ▼
Automated reply / message sends the free "Am I On Track?" reading check
        │
        ▼
Parent gives email to receive the tool  ──►  added to email nurture list
        │
        ▼
Parent runs the checklist for their child's age band
        │
        ▼
        ├─ 0–2 signs ─► "Keep watching" — recheck later
        ├─ 3–5 signs ─► "Worth a closer look" — request school eval in writing + start light practice
        └─ 6+  signs ─► "Act now" — pursue a specialist, request eval, start evidence-based practice tonight
```

**Goal of the flow:** reduce fear, give an immediate next action, and capture an email for nurture toward a toolkit purchase.

---

## Flow 2 — Consideration → purchase (current sales flow)

```
Email nurture + social content build trust
        │
        ▼
Parent reaches a product page for a toolkit (e.g., Summer)
        │
        ▼
Sees what it is, who it's for, the evidence behind it, and the price
        │  (price framed against $75–100/session tutoring)
        ▼
Purchases via the sales platform (one-time download)
        │
        ▼
Receives the downloadable bundle (printable tools + welcome packet + reference card)
```

**Edge cases to consider:** the parent who doesn't yet know their child is dyslexic (enters via myth-bust content, not search); the cost-locked family; the parent who buys for the wrong grade band and needs to switch or cross-buy.

## Flow 3 — Onboarding into the toolkit (first use)

```
Parent opens the welcome packet
        │
        ▼
Understands: how the program works, session length, how many sessions/week,
the specialist-first message, and how to pick the right track for their child
        │
        ▼
Parent reviews the 4 units and the 20 tools
        │
        ▼
Parent selects the starting tool(s) and gathers simple materials
(letter tiles, paper, craft sticks, a timer — minimal)
        │
        ▼
Parent reads the tool's parent guide + coaching notes (2–3 min)
        │
        ▼
Ready to run first session
```

---

## Flow 4 — Daily/weekly session (core repeated workflow)

```
Parent picks tools for today (one per unit, per the week's plan)
        │
        ▼
SESSION (15–20 min):
  0–5 min   Sound Play     → parent models → child attempts → celebrate effort
  5–10 min  Word Work      → model with manipulatives → "I do, we do, you do"
  10–20 min Read & Fluency → child reads instructional-level text aloud
                              → parent corrects errors immediately
                              → optional reread for fluency
  (woven)   Comprehension  → scaffolded questions / retell / "wonder" prompts
        │
        ▼
Log the session (consistency), note any win in the celebration log
        │
        ▼
(Outside session) 10–15 min daily audiobook / audio-assisted reading
        │
        ▼
Repeat ~2x/week (Summer) or per the full-program cadence
```

**Decision points inside a session:**
- **Child frustrated?** → stop early; "a 5-minute win beats a 15-minute struggle."
- **Child misses >1 word in ~10?** → text is too hard; drop to easier instructional-level text.
- **Child guesses from pictures/first letter?** → cover the word, rebuild from sounds, retry.

---

## Flow 5 — Tracking progress over weeks

```
Each session  → mark weekly session log (consistency)
Repeated reads → record cold/practiced/performance times (or "felt easier?" for young readers)
Skill mastered → check it off on the skills checklist
Notable win    → write it in the celebration log (kept visible to the child)
        │
        ▼
Over weeks: visible growth → child's confidence rises; parent sees consistency + gains
```

## Flow 6 — Future app session flow (envisioned)

```
Open app ─► "What tool today?" (suggested session)
        │
        ▼
Browse/practice library (filter by kit/skill) ─► open a tool
        │
        ▼
Tool detail: Overview │ Practice │ Quick Reference
        │
        ▼
Start active session ─► timer counts UP, tips available, distraction minimized
        │
        ▼
End session ─► capture mood (smooth/good/tough/tired) + optional note
        │
        ▼
Progress updates (sessions + time + skills + milestones; never accuracy %)
        │
        └─ Guide tab available throughout (how-to / what-if / why-this articles)
```

---

## Flow 7 — Future path to a specialist (envisioned)

```
Parent decides they want professional help (or screener said "act now")
        │
        ▼
Searches the specialist directory by location / certification / age specialty / price / format
        │
        ▼
Views a vetted tutor's profile ─► contacts them directly
```

**This flow fulfills the product's specialist-first promise** — the product actively helps the parent leave the self-serve track for professional help when appropriate.
