# Design Context — START HERE (rebrand handoff)

This folder is the **complete, self-contained briefing** for a fresh rebrand/redesign of
Phono. It describes the customer, product, business, goals, and constraints with **no
previous visual identity** in it.

## Read in this order
1. **`design-brief.md`** — the single doc that stands alone if you read nothing else.
2. `01-product-summary.md` … `08-open-questions.md` — depth on each area.

## Ground rules for a redesign
- **Use only this folder** (plus the design-free instructional *content* under
  `../products/toolkits/**/v2-structured/` if you need the actual reading activities).
- **Do NOT open `../archive/old-brand/`.** It holds the previous logo, colors, typography,
  design system, UI specs, and branded outputs — quarantined on purpose. Looking at it
  defeats the rebrand.
- Other working notes in the vault may mention past visual decisions in passing; they are
  not a design source. This folder is.
